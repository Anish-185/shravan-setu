# shared/fixtures/

Test vectors run by BOTH rule engines: pytest (`server/referrals/tests/test_rules_fixtures.py`, Python reference)
and jest (`screener/src/rules/__tests__/fixtures.test.ts`, JS port). Both must match every `expected` exactly.

- One file per function: `decide_outcome`, `rescreen_plan`, `apply_500hz_policy`, `triage_route`, `reliability_score`,
  ..., and `verify_audit_chain` (audit hash chain; its chains are built with hashlib in the generator).
- Each case: `name`, `input`, optional `config_overrides` (`{"dotted.path": value}`), then `expected` or `expected_error`.
- `fixture_config.json` is a frozen copy of `config/screening.json`; a test checks it has the same shape.
- Generated by `python scripts/make_rule_fixtures.py`. Inputs are built by helpers; every `expected` is written by
  hand in that script, never computed by an engine.

Run both: `scripts/check_rules_parity.sh`.
